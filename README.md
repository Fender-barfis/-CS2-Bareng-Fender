# Travel Fare Calculator

## Description
This program calculates the total fare based on the distance, fare rate, and passengers.

## Version 1 - Original code without input validation 
- Input: Accepts passenger name, distance in kilometers, and the number of passengers
- Process: Calculates the total travel fare by multiplying the distance, fare rate, and number of passengers.
- Output: Displays the passenger's name and the calculated total fare.
- Does not include input validation
